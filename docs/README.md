# Documentación de ServerSetup CLI

Documentación completa en español del proyecto `serverforge-cli`.

- **[Guía de usuario](guia-usuario.md)** — instalación, uso del comando `sforge`,
  todos los módulos disponibles con sus flags y ejemplos, y el flujo `--all`.
- **[Arquitectura](arquitectura.md)** — cómo está organizado el código, por qué
  se eligió este diseño, cómo añadir un módulo nuevo y las convenciones de
  testing. Pensado para quien vaya a contribuir o modificar el proyecto.

> Para el listado de cambios entre versiones consulta [`../CHANGELOG.md`](../CHANGELOG.md).
> El `README.md` de la raíz del repositorio mantiene un resumen equivalente,
> tanto en [español](../README.md) como en [inglés](../README.en.md); estos
> documentos amplían ese resumen con más detalle y una sección dedicada a
> arquitectura para desarrolladores.
